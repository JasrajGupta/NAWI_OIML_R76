# NAWI-OIML-R76

## NAWI OIML R-76 Test Report Generator

A web-based prototype designed to digitize and streamline the testing and reporting workflow for **Non-Automatic Weighing Instruments (NAWI)** based on the OIML R-76 testing framework.

The system provides a structured workflow for application creation, instrument identification, test setup, test execution, metrological calculations, compliance evaluation, officer review, approval, and standardized test-report generation.

> **Note:** This project is a prototype and is not an OIML-certified testing or verification system. Its workflow and reporting structure are informed by the referenced OIML R-76 requirements and related legal-metrology/software guidance.

---

## 🚀 Key Features

- 🔐 Role-based authentication
- 👥 Administrator, Testing Officer, Reviewing Officer, and Viewer roles
- 📊 Application dashboard
- 📝 New test application workflow
- 🔬 Instrument identification and specification
- 🌡️ Test setup and environmental conditions
- ⚖️ OIML R-76 test modules
- 🧮 Automated metrological calculations
- ✅ Pass/Fail compliance evaluation
- 📋 R-76-4 checklist support
- 👨‍💼 Review and approval workflow
- 📄 Automated test-report generation
- 🗂️ Report repository
- 👥 User management
- 📈 Application status and statistics
- 🔎 Search and retrieval of test reports
- 🕒 Structured traceability of application and test information
